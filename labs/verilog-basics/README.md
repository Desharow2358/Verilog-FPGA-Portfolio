# Two-Digit Adder with Seven-Segment Display

## Overview

This project implements a two-bit full adder using Verilog HDL. The addition result is displayed as a decimal number on a seven-segment display.

## Design

- **HDL:** Verilog
- **Tool:** Vivado
- **Board:** EGO1 FPGA
- **Function:** Add two binary inputs and display the decimal result on a seven-segment display.

## Source Code

- `two_digit_adder.v` — Top-level Verilog module.

## Verification

The design was tested through functional simulation and FPGA hardware verification.

## Learning Objectives

- Understand Verilog module design.
- Implement binary addition logic.
- Drive a seven-segment display.
- Verify the design using simulation and FPGA hardware.
