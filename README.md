## Featured Labs

### 1. Two-Digit Adder

A digital arithmetic circuit implemented in Verilog with a seven-segment display interface.

- Designed and implemented a two-digit addition circuit.
- Practiced combinational logic design and arithmetic operations.
- Verified circuit behavior through simulation.

**Topics:** Verilog, Combinational Logic, Arithmetic Circuits, Seven-Segment Display

### 2. LED Control and Counter

Digital circuits for LED control and timing-based behavior.

- Implemented counter-based timing logic.
- Explored LED blinking and sequential circuit behavior.
- Practiced clock-driven design and parameter-based timing control.

**Topics:** Counters, Sequential Logic, Clock Dividers, FPGA I/O

### 3. Finite State Machine Design

Implemented FSM-based control logic using Verilog.

- Practiced state definition, state transitions, and output logic.
- Explored FSM coding styles and control-oriented RTL design.
- Applied simulation to verify state transition behavior.

**Topics:** FSM, Sequential Logic, RTL Design, Control Logic

### 4. Alarm System

A digital alarm system developed using modular Verilog design and simulation.

- Designed alarm-related control logic.
- Integrated display-related modules.
- Created a testbench to verify alarm triggering and event counting.
- Used simulation results to validate functional behavior.

**Topics:** Modular RTL Design, Testbench, Behavioral Simulation, FPGA Design

## Development Workflow

My typical FPGA development workflow includes:

1. Design the circuit and define its behavior.
2. Implement the RTL modules in Verilog.
3. Create testbenches for functional verification.
4. Run behavioral simulation in Vivado.
5. Apply FPGA pin constraints.
6. Synthesize and implement the design.
7. Test the design on the FPGA development board when applicable.
